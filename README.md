# CODE-VVOD
app for puzzles with codes

!WARNING! for start need to python and python-tk or python3 and python3-tk
DOWNLOADING
1. download zip file and unzip
2. write all codes in codes.txt via ||
3. open terminal in this file
4. if you have python:
     python CODE-VVOD.py
5. if you have python3:
     python3 CODE-VVOD.py
